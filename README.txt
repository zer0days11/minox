Minox - iPhone app (PWA)

1. Upload every file in this folder to a GitHub repository (or any HTTPS static host).
2. GitHub: Settings > Pages > Branch: main, folder: / (root) > Save.
3. Open https://<your-username>.github.io/<repo>/ in Safari on the iPhone.
4. Share > Add to Home Screen > Add.

Your logs and photos stay on the phone (IndexedDB). Use Settings > Backup once a month.
